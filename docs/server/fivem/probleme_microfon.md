## Setare microfon

Pentru a-ți seta microfonul pe FiveM trebuie să faci următoarele:
1. Intră în meniul de setări al jocului.
2. Selectează tabul **Settings** - **Settings**.
3. Setează opțiunea de **Microphone Enabled** pe **On**.
4. Selectează-ți microfonul corect la **Input Device**.
